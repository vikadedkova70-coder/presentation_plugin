# Контракт API экспорта презентаций 

Сервис принимает презентацию PowerPoint из плагина и сохраняет её в хранилище.

Адрес сервера:
- локально: `http://localhost:8000`
- на сервере: будет добавлен после деплоя

## 1. Загрузить презентацию

`POST /api/exports`

Тип запроса: `multipart/form-data` (обычная форма с файлом).
Заголовок `Content-Type` вручную не указывать: браузер добавит его сам.

| Поле | Тип | Обязательно | Ограничения |
|---|---|---|---|
| `title` | текст | да | 1–255 символов |
| `description` | текст | нет | до 2000 символов |
| `tags` | текст | нет | теги через запятую, максимум 20 |
| `file` | файл | да | расширение `.pptx`, размер до 100 МБ |

### Успех: код 201

```json
{
  "id": 1,
  "title": "Отчёт Q3",
  "status": "success",
  "sha256": "ab12...",
  "drive_file_id": "1AbC...",
  "drive_url": "https://drive.google.com/file/d/1AbC.../view"
}
```

`drive_url` — ссылка, которую нужно показать пользователю.
Пока включена заглушка, ссылка вида `https://example.com/stub/...`.

### Ошибки

| Код | Когда | Что показать пользователю |
|---|---|---|
| 400 | файл пустой или повреждён | «Файл не похож на презентацию PowerPoint» |
| 409 | такая презентация уже загружена | «Уже есть в библиотеке» + ссылка из `detail.drive_url` |
| 413 | файл больше 100 МБ | «Файл слишком большой» |
| 415 | не `.pptx` | «Поддерживаются только файлы .pptx» |
| 422 | не заполнено название | «Укажите название» |
| 502 | не удалось сохранить в хранилище | «Хранилище временно недоступно, повторите позже» |

Формат тела ошибки: `{"detail": "текст"}`.
Для 409 `detail` — объект: `{"detail": {"message": "...", "drive_url": "https://..."}}`.

## 2. Журнал загрузок (для страницы администратора)

`GET /api/exports?limit=100`

Если на сервере задан токен, нужен заголовок `X-Admin-Token: <токен>`; без него код 401.

Ответ 200 — массив, новые записи первыми:

```json
[
  {
    "id": 1,
    "title": "Отчёт Q3",
    "description": "...",
    "tags": "продажи,2026",
    "filename": "report.pptx",
    "sha256": "ab12...",
    "size_bytes": 1048576,
    "status": "success",
    "drive_url": "https://...",
    "error": null,
    "created_at": "2026-11-02T10:15:00.000Z"
  }
]
```

`status`: `success` (загружено), `failed` (ошибка, текст в `error`), `pending` (в процессе).

## 3. Проверка, что сервер жив

`GET /health` → `{"status": "ok"}`
